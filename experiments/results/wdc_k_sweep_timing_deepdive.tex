\footnotesize
\begin{tablenotes}
\item[a] Per $k$: 5 independent repeats of the SAME query set at that $k$ (query eligibility/skip is $|D_{union}|\geq k$, so which queries are eligible differs by $k$ -- $k$=100 skips 1 more query than $k$=10..90; $k$=639 skips several more, see the skipped counts above). \emph{n\_selected}, \emph{n\_skipped}, \emph{n\_clamped}, and \emph{n\_feasible} are identical across all 5 repeats at a given $k$ (enforced by assertion); only step wall-clock cost is re-measured each repeat, against ONE shared context (semantic HNSW index + overlap posting-list index) built once for tier\_100k and reused across every $k$ and every repeat.
\item[b] Stage 1/Stage 2 solve times are heavily right-skewed per query (most queries solve in low single-digit ms; a few take far longer), so Mean/Median/Min/Max are all computed by pooling every query's timing across all 5 repeats into one sample per $k$ -- the same repeated-and-pooled methodology used in and explained fully by \texttt{wdc\_step\_timing\_deepdive.tex} (right-skew instability + the HNSW add\_items() construction non-determinism found there); not repeated in full here to avoid duplicating that explanation across 11 $k$ values.
\end{tablenotes}
